# RClauncher PowerShell edition

常駐型のクリック起動ランチャーを、Windows PowerShell 5.1 以降で動く単一の `.ps1` に移植したものです。

## 起動方法

`rclauncher.ps1` を実行してください。STAで起動されていない場合は、STAのPowerShellプロセスを起動し直します。設定ファイルが存在しない場合は初回起動時に作成し、履歴用フォルダも作成します。設定ファイルはスクリプトと同じフォルダに置かれます。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -STA -File .\rclauncher.ps1
```

## 機能

- デスクトップの空白部分をダブルクリックして、登録フォルダとアプリのメニューを表示します。フォルダ名をクリックするとそのフォルダを開き、ホバーすると子フォルダのメニューを表示します。右クリックではWindowsのフォルダメニューを表示します。子項目はメニューを開いたときに読み込みます。
- デスクトップ以外で右クリックを2回すると、テキストクリップボード履歴を表示します。選択したテキストをクリップボードに戻して貼り付けます。
- タスクトレイメニューから設定UI、設定の再読み込み、設定フォルダの表示、終了を操作できます。`config.toml` の直接編集も約2秒以内に反映します。
- 履歴はスクリプトと同じ場所の `clipboard\clipboard_history.txt` と `folder_launch\folder_history.txt` に保存します。

## 設定

設定UIではフォルダとアプリの追加・編集・削除・並べ替え、履歴件数などを変更できます。フォルダ／アプリの各タブでは一覧の下に操作ボタンがあります。変更後はウィンドウ下部の「保存して閉じる」を押してください。パスでは `%USERPROFILE%` などの環境変数を使用できます。既存の設定形式はREADMEの元版および同梱の `config.toml` を参照してください。

クリップボード履歴は平文で保存されます。パスワードなど機密情報のコピーに注意してください。

## 制限

- グローバルマウスフックのため、管理者権限で実行されるアプリ上での検知にはランチャーも管理者権限で起動する必要があります。
- ExplorerのコンテキストメニューはWindows Shellが公開する動詞を表示します。元のRust版のように各シェル拡張へメニュー描画メッセージを転送する処理は含みません。
- デスクトップのアイコン一覧が別の権限で実行されるなど、Explorerのリストビューを検査できない場合は、アイコン一覧内のクリックを空白として扱いません。
