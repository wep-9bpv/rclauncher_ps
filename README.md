# RClauncher（PowerShell版）

Windows PowerShell 5.1 以降で動作する、常駐型のクリック起動ランチャーです。ランチャー本体は単一の `.ps1` ファイルで構成されています。

## 起動方法

`rclauncher.ps1` を実行してください。STAモードで起動されていない場合は、STAモードのPowerShellプロセスを起動し直します。初回起動時に設定ファイルが存在しなければ作成し、履歴保存用のフォルダーも作成します。設定ファイルはスクリプトと同じフォルダーに保存されます。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -STA -File .\rclauncher.ps1
```

## 機能

- デスクトップ上の何もない場所をダブルクリックすると、登録済みのフォルダーやアプリのメニューを表示します。フォルダー名をクリックするとそのフォルダーを開き、マウスポインターを重ねると子フォルダーを表示します。フォルダーを右クリックすると、Windowsのコンテキストメニューを表示します。子項目はメニューを開いたときに読み込みます。
- デスクトップ以外の場所で右クリックを2回行うと、テキストのクリップボード履歴を表示します。履歴から選ぶと、そのテキストをクリップボードに戻して貼り付けます。
- タスクトレイのメニューから、設定画面を開く、設定を再読み込みする、設定フォルダーを開く、アプリを終了する操作ができます。`config.toml` を直接編集した場合も、約2秒以内に変更が反映されます。
- 履歴はスクリプトと同じ場所にある `clipboard\clipboard_history.txt` と `folder_launch\folder_history.txt` に保存されます。

## 設定

設定画面では、フォルダーやアプリの追加・編集・削除・並べ替えのほか、履歴の保存件数などを変更できます。「アイコンを表示」のチェックを外すと、アプリとフォルダーのメニューアイコンを非表示にできます。各タブの一覧の下にあるボタンから操作してください。変更を保存するには、ウィンドウ下部の「保存して閉じる」を押します。パスには `%USERPROFILE%` などの環境変数を使用できます。設定ファイルの記述例は、同梱の `config.toml` を参照してください。

クリップボードの履歴は暗号化せずに保存されます。パスワードなどの機密情報をコピーする際はご注意ください。

## 制限

- グローバルマウスフックを使用するため、管理者権限で実行中のアプリ上で操作を検知するには、ランチャーも管理者権限で実行する必要があります。
- Explorerの右クリックメニューは、Windows Shellから取得した項目で構成されます。元のRust版とは異なり、各シェル拡張機能にメニューの描画を依頼する処理はありません。
- Explorerのリストビューを検査できない場合（デスクトップのアイコン一覧が別の権限で実行されている場合など）、アイコン上のクリックを空白部分のクリックとして扱いません。
